# 飞牛 PT 下载：原生 qBittorrent 5.2.4，非 Docker，支持手机管理与 MoviePilot

## 📌 简介

分享一个为飞牛 fnOS 制作的下载应用——**飞牛 PT 下载**。

后台使用开源 **qBittorrent-nox 5.2.4**，以原生进程运行，不依赖 Docker；前端不是直接套用 qB 原版 WebUI，而是重新制作了面向电脑和手机的中文管理页面。

目标是把 PT 常用的下载、保种、Tracker 排障、分享率控制、时段限速和 MoviePilot 接入放到一个界面里，减少在手机上操作桌面表格、翻后台日志的麻烦。

- 应用版本：**1.4.8**
- 内核版本：**qBittorrent 5.2.4**
- 支持架构：**x86_64（Intel / AMD）**，目前不提供 ARM 包
- 开发维护：**alvin-7**
- 项目仓库：https://github.com/alvin-7/fnos-qbittorrent
- 原创代码许可证：**GPL-3.0-or-later**；第三方组件遵循各自许可证

> 第三方社区项目，非飞牛官方产品，也不是 qBittorrent 官方发行版。当前持续完善中，欢迎试用反馈；不能把本地回归测试等同于所有 fnOS 设备和手机的兼容性保证。

## ✨ 主要特点

### 原生安装，不依赖 Docker

使用 FPK 安装，后台直接运行 qBittorrent-nox 和飞牛网关适配进程，纳入应用中心的启停与状态管理。

不是“Docker 外面套一个图标”，也不需要额外部署容器来运行下载内核。

### 飞牛入口与自定义中文页面

通过飞牛应用入口访问，复用 fnOS 登录态；提供电脑与手机响应式布局。飞牛页面入口和 MoviePilot 服务入口相互独立，不需要把 qB 内部管理端口开放出来。

### PT 优先，不靠开启发现功能解决问题

新安装默认关闭 **DHT、PeX、LSD 和 UPnP**，使用固定高位 BT 端口，界面可修改端口。升级保留已有用户配置，请以设置页实际读回值为准。

不自动添加公共 Tracker，不修改种子的 private 标记。不同 PT 站对客户端版本、保种时间和分享率的要求不同，请以站规为准。

## 🧰 功能清单

### 下载与保种

- 添加磁链、`.torrent` 文件及 HTTP/HTTPS 种子下载链接。
- 支持带查询参数、没有 `.torrent` 后缀的站点下载地址。
- 添加时可选择分类、标签和暂停状态，默认请求开始。
- 支持开始、强制开始、暂停；已完成任务可以继续做种。
- 支持选择模式及批量开始、强制开始、暂停、设置标签和分类。

### 标签与分类管理

- 从 qB 后端读取真实分类、标签和任务。
- 支持浏览、搜索、选中高亮及查看关联任务。
- 显示关联任务计数和分类保存路径。
- 默认浏览不显示复选框；进入选择模式后提供批量操作。
- 写入后读取 qB 状态确认结果，不只修改页面显示。

### 限速与分享率

- 正常及备用模式的全局上传、下载限速。
- 按 NAS/qB 本地时间执行的单时段限速计划。
- 支持每日、工作日、周末及指定星期；部分跨午夜组合有界面限制。
- 高级设置提供分享率控制，新安装默认阈值 **0.1**，达到后停止做种，不删除任务和文件。
- 可以调整或关闭分享率限制；升级不静默覆盖已有策略。

**特别提醒：0.1 只是应用预设，不代表满足任何 PT 站的最低要求。请按站规和个人保种计划调整。**

### Tracker 与添加失败诊断

- 展示连接/已知种子与 Peer、Tracker 状态、错误消息、可用性、速度和任务状态。
- 对私有种子的 DHT/PeX/LSD 提示与真实 Tracker 错误作区分。
- HTTP 添加被接受但未生成任务时，继续检查任务及后台错误，不把 HTTP 202 当成添加成功。
- 无效种子内容等错误可在页面显示，例如 `bdecode:4`；诊断不暴露完整 PT 签名链接。
- 无法严格关联到当前请求的时段日志会明确标注“关联未确认”，不猜测站点响应内容。

### MoviePilot 接入

高级设置提供独立 MoviePilot 连接器，**默认关闭**。启用后设置专用账号、密码和端口，默认端口为 **18081**。

同一台 NAS 的 MoviePilot Docker 容器，如果已经配置好 `host.docker.internal` 到宿主机的访问，可填写：

```text
下载器类型：qBittorrent
地址：http://host.docker.internal:18081
账号：连接器中设置的账号
密码：连接器中设置的密码
```

如果 MoviePilot 将主机和端口分开填写，主机填 `http://host.docker.internal`，端口填 `18081`。

- 无需填写容器 CIDR。
- 支持 qB API 协议路径内的透明业务转发，不逐项维护业务端点白名单。
- 连接器管理、私有诊断及文件路径不作为外部业务 API 开放。
- 支持密码显示/隐藏；旧版仅存哈希的密码需重新设置后才能显示。
- 禁用连接器或轮换配置时撤销旧会话。

连接器可监听全部 IPv4 接口，**网络隔离依赖 NAS 防火墙**。只用于可信网络，不要将 18081 映射到公网。连接器账号具有广泛 qB 业务操作能力，应作为管理凭据保护。

**连接成功不等于媒体整理已可用：**MoviePilot 容器下载目录与 qB 的 NAS 实际下载路径还需要正确挂载、映射和授权。

## 📱 手机交互

- 默认以任务卡片展示状态，不把桌面表格简单缩小。
- 分类和标签提供独立浏览区域与筛选反馈。
- 点击“选择”后再出现适当尺寸的复选框，触控区域保留约 44px。
- 选择模式提供手机底部批量操作栏。
- 设置与详情关闭按钮保持可见，点击外部遮罩可关闭。
- 优化点击高亮残留和异步操作状态，提交期间显示处理中，失败时保留可读提示。

> 发帖前请确认 Release Assets 中已经上传对应 FPK、源码材料及校验文件。仅有 Git tag 不代表安装包已发布；不要在资产尚未上传时宣传“已可下载”。

安装步骤：

1. 在 fnOS 应用中心选择手动安装。
2. 选择 x86_64 FPK，按向导完成安装与目录授权。
3. 从飞牛应用入口打开“飞牛 PT 下载”。
4. 确认下载目录、BT 端口、分享率与限速设置。
5. 需要 MoviePilot 时，再到高级设置启用连接器。

已有 Docker qB 用户请先备份。**本项目不承诺自动迁移旧 Docker 的任务、恢复数据和 `/downloads` 路径**，不要直接覆盖旧配置。

## 📊 包体与资源占用

1.4.8 对发布二进制进行了调试信息裁剪，安装包由 **38,403,677 字节**降至 **33,622,282 字节**，约减少 **12.45%**。

这项优化减小的是安装包和磁盘占用，**不保证运行内存下降**。当前一台用户 NAS 上显示 qB 约 43MB、网关约 10MB；仅作个例参考，任务数量、连接数、缓存和系统统计口径都会影响内存，不能当作所有设备的性能承诺。
