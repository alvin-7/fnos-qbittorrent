## 1. 目标与边界

为 MoviePilot 提供一个**独立、受控、可撤销的 qB 客户端兼容入口**。入口由本应用服务端代理到本机 qB 5.2.4 标准 API，网页高级设置负责启停、凭据和可观察状态。

### 必须达到

1. 默认禁用；启用前必须由管理员明确确认保存。
2. 启用后只监听经选定网络拓扑允许的地址；入口状态显示实际地址、端口、监听范围和 qB 探测结果。
3. 账号密码仅用于 MoviePilot 入口认证；用户当次输入/标准 login 传输是必要使用，不得持久化在 HTML/JavaScript、URL、日志、错误或 qB 代理日志中。
4. 禁用后立即停止入口、撤销入口会话/凭据验证能力；已有连接必须被关闭或在下一请求失败。
5. 所有业务结果来自 qB 5.2.4 标准 API 的真实请求与回读。
6. 连接测试只能读取 API，不添加、暂停、删除、改标签/分类或改变任何任务。

### 明确不做

- 不把 qB 管理 API `127.0.0.1:18080` 暴露到公网或任意 LAN。
- 不使用 BT 端口 `49160` 作为管理入口，也不代理 BT 协议。
- 不把飞牛浏览器/App 统一网关当成 MoviePilot 通用 API；其认证、来源和生命周期与本入口分离。
- 不在入口中实现 MoviePilot 业务编排、下载器数据库或第三方凭据托管。
- 不接受“透明转发所有路径”的实现作为默认方案；危险/未知路径必须拒绝。

## 2. 已知拓扑与推荐方案

### 2.1 当前事实

- qB Web API：仅 `127.0.0.1:18080`。
- BT 监听：`49160`，仅用于 BitTorrent 流量。
- 飞牛统一网关：面向浏览器/App，不是通用服务端 API。
- 当前没有 MoviePilot 专用入口、独立凭据或 API key。

### 2.2 已收敛拓扑：同 NAS 的标准 HTTP qB 兼容入口

**已确认**：MoviePilot 是同一台飞牛 NAS 的 Docker 容器，已经通过 `host.docker.internal` 访问宿主机。无需再次要求用户确认 Docker 模式或地址；这不等于连接器已实现或 18081 已监听。

`MoviePilot qB 下载器 → http://host.docker.internal:18081（示例，端口 proposed） → Connector → 127.0.0.1:18080 qB`

- 标准 HTTP qB Web API 是客户端契约；MoviePilot 不需定制插件、Unix socket URL 或自定义 REST 适配。Unix socket 只可能属于应用内部/浏览器网关传输，不是 MoviePilot 客户端地址。
- 专用端口建议 **18081（proposed，待 NAS 冲突检查）**，管理员可配置；不得与内部 `18080`、BT `49160` 混用。
- 只绑定管理员确认的明确 NAS 监听 IP，并限制明确来源 IP/CIDR。禁止默认 `0.0.0.0`、`::` 或放行所有 RFC1918；来源不明则保持关闭，不能自动扩大网段。
- `host.docker.internal` 是已使用的容器 DNS 别名，不是宿主可绑定 IP。实施时探测其实际解析目标，选择实际 Docker 宿主可达接口 IP，并验证绑定后路由、实际来源 NAT/IP/CIDR 和防火墙；不凭空写固定网段，不盲绑 `127.0.0.1`，不改成全接口监听。Docker bridge 的容器 loopback 是自身；host network 则共享宿主网络，下面仅作差异说明而非重新询问部署模式。
- host network：容器共享宿主网络，loopback 语义与 bridge 不同；可使用已绑定的 NAS IP。只有显式改为 loopback 监听并验证后，`127.0.0.1:<连接器端口>` 才可作为该模式地址，绝不是内部 `18080`。
- HTTP 是实际明文传输（账号密码和业务数据均无加密），只适用于可信 NAS 内网/容器网络；不可信网络必须先设计并验证 TLS 入口/可信反代及来源边界，否则阻止启用，不宣传“同 NAS 即安全”。不新增公网映射。
- Host/authority、协议、来源 CIDR 和独立凭据共同限制；代理头不代替 socket peer 来源。路由/NAT/公网反代不可绕过，须做外网负向验收。

### 2.3a 低摩擦、安全发现

高级设置提供“发现建议/重新检测”：在后续授权实施阶段只读发现本机接口、端口占用、可见 Docker 网络及候选网关，标注来源、时间、置信度和“未验证/已在容器内验证”。不读取容器环境变量中的秘密、不扫描任意网段、不修改 Docker/防火墙/qB。检测权限不足时保留手动入口并给出最小步骤，不要求用户一次手填全部未知信息。

候选 IP、18081 和最小来源 CIDR可预填为草稿，用户确认后才保存；无可靠来源不预填宽网段。多接口提供可理解的名称和选择理由。无法从 MoviePilot 容器发起测试时明确“仅 NAS 本机验证，容器可达性待验证”，不把后台 loopback 自测当作 MoviePilot 已连接。

**禁止方案**：qB 直接改成 LAN/公网监听、复用 BT 49160、把 FN Connect/浏览器网关 URL 当作 MoviePilot 的服务端连接地址。

### 2.3 连接模式决策

实现建议采用**受控代理模式**：仅提供第 5 节白名单端点，逐请求认证、校验方法/参数、转发到 qB、按端点做响应过滤和安全审计。不是透明反代。

透明转发仅可作为后续明确批准的兼容性实验，必须有：路径白名单、方法白名单、响应头过滤、Host/来源约束、未知路径 404、危险 GET mutation 防护和完整验收；不得作为首版默认。

## 4. 凭据与安全模型

### 4.1 保存方案（必须在实现前决策）

优先级：

1. **系统密钥存储**：若 fnOS/包运行时提供可访问且有权限隔离的 secret store，保存入口密码或加密密钥，不把明文写入配置。
2. **包私有凭据文件**：仅当无可用密钥存储时使用。父目录 `0700`，凭据文件新建即 `0600`，归属包用户；写入采用同目录临时文件 `0600` + fsync + 原子 rename。不得放在 Web 静态目录、共享下载目录或可被容器普通用户读取的路径。
3. 不能可靠保证上述权限（尤其挂载盘/Windows ACL/共享卷）时，阻止启用并明确提示，而不是降级为明文或仅依赖 `chmod`。

**不保存明文密码的替代路径**：若入口仅需验证密码，可存储 Argon2id（或系统批准的等价慢哈希）哈希；随机盐、参数版本和校验元数据同样按私有文件权限保护。哈希不可反推，但不能用于向 qB 登录；Connector 到 qB 使用本机受限调用/既有内部认证机制，不能把 MoviePilot 密码复用为 qB 密码。若实现需要重启后继续验证，密码哈希必须持久化；若系统密钥存储支持加密 secret，则可以保存随机验证密钥/加密凭据。

### 4.2 初始密码与变更

推荐：首次进入高级设置时管理员必须设置随机生成的高熵初始密码，页面只显示一次“已设置”，不展示密码值；管理员可主动轮换。禁止固定默认密码、日志打印初始密码、把密码放入安装 URL/环境变量/前端源码。

保存/启用必须二次确认：确认文案说明入口范围、密码将仅用于 MoviePilot、启用后可被 allowlist 内客户端访问。修改密码后立即撤销所有旧入口会话；账号修改同样处理。

### 4.3 认证、CSRF、Host 与来源

- MoviePilot 使用标准 `POST /api/v2/auth/login` 表单 `username/password` 登录，Connector 验证独立专用账号并签发自己的 qB 客户端兼容 cookie/session；支持 logout、过期、并发/数量限制。不能要求 MoviePilot 改用 Basic、API key 或自定义认证头。
- cookie 名称、Path、SameSite、HTTP/TLS Secure 行为和成功/失败返回格式需与目标 MoviePilot qB 客户端实测；不得仅凭 login HTTP 成功认定认证成功，必须继续读受保护版本 API。无 Origin 的服务客户端允许在凭据、Host、来源全部通过后登录；存在恶意 Origin/Referer 的请求拒绝，不要求伪造浏览器头。
- 外部 cookie 与 qB backend SID 完全分离，绝不透传 backend Set-Cookie、密码或 SID。禁用、账号/密码变更、重启立即注销全部旧会话；不允许自动复活或以 backend 密码作为客户端密码。
- 管理网页保存/启停请求复用现有受保护管理 API 的 CSRF、Host、Origin/Referer 和 Fetch Metadata 校验。
- Connector API 单独执行 Host allowlist、来源策略、方法 allowlist；不接受任意 `Origin: *`、跨站表单或客户端自带伪造身份头。
- 不信任未经验证的 `X-Forwarded-*`；若有反代，必须配置固定可信 hop，并保留客户端来源校验。
- 返回固定、脱敏错误码；不反射 Authorization、Cookie、密码、完整 URL、查询签名或 qB 内部地址。

### 4.4 防暴力与审计

按账号 + 源地址 + 入口实例计数失败；指数退避，达到阈值临时锁定，成功后清理该账号的失败计数但保留审计事件。应有总并发/请求速率上限，避免认证端点成为 DoS 放大器。

审计只记录：时间、入口实例、结果（成功/失败）、固定失败原因、脱敏源网络标识、请求方法和 allowlisted endpoint 名称、配置版本/会话撤销事件。禁止记录密码、Authorization、Cookie、qB SID、完整 Host/URL/query、任务下载 URL、磁力链接或 passkey。

## 5. MoviePilot 常见 qB API 兼容矩阵

以下均指 qB 5.2.4 标准 Web API；Connector 对外可沿用相同路径/字段以减少 MoviePilot 适配成本，但由代理实现明确白名单。表中“透明”仅表示可按原 qB 语义转发，不表示允许任意路径。

| 能力 | qB 标准端点/方法 | Connector 首版 | 语义与验收 |
|---|---|---|---|
| 登录/会话探针 | `/api/v2/auth/login`（qB 原生认证） | 代理适配 | Connector 使用自身凭据；不把 MoviePilot 密码转发为 qB 密码；登录后必须用只读 API 验证 |
| 版本/能力 | `/api/v2/app/version`、`/api/v2/app/webapiVersion` | 透明白名单 | 返回真实 qB 版本/API 版本，不写入 |
| 全局偏好 | `/api/v2/app/preferences` GET | 透明白名单 | 只读测试可用；禁止通过测试修改偏好 |
| 任务列表 | `/api/v2/torrents/info` GET | 透明白名单 | 支持 hash/category/tag 等 qB 参数；返回真实状态 |
| 任务详情 | `/api/v2/torrents/properties` GET | 透明白名单 | 仅 hash 查询；错误原样映射为安全错误 |
| 添加任务 | `/api/v2/torrents/add` POST | 代理实现 | 首版允许 MoviePilot 业务调用，但不属于“连接测试”；参数白名单、大小/类型限制、禁止日志回显 URL/磁链 |
| 删除任务 | `/api/v2/torrents/delete` POST | 代理实现/显式策略 | `deleteFiles` 默认 false；是否开放须单独管理员决策；不得由测试调用 |
| 开始/停止/暂停 | `/api/v2/torrents/start`、`stop`、`pause`、`resume` | 代理实现/显式策略 | 仅允许 POST；不把 GET mutation 放行；测试不得调用 |
| 分类读取 | `/api/v2/torrents/categories` GET | 透明白名单 | 返回真实分类映射和 save path |
| 分类创建/编辑/删除 | `createCategory`、`editCategory`、`removeCategories` | 代理实现 | 参数白名单；写后重新 GET categories 与相关 torrent info 回读 |
| 标签读取 | `/api/v2/torrents/tags` GET | 透明白名单 | 返回 qB 真实标签 |
| 标签创建/删除 | `createTags`、`deleteTags` | 代理实现 | qB 5.2.4 逗号分隔语义需严格编码；不得把用户值拼入 URL |
| 任务标签 | `addTags`、`removeTags` | 代理实现 | `hashes` 使用 qB 约定的 `|`；写后 `torrents/info` 回读 `tags` |
| 标签替换 | `setTags` | 不首版假定 | qB 5.2.4 不作为基础端点；如 MoviePilot要求，需真实探测后单独兼容 |
| 标签/分类事实边界 | 上述 qB 标准端点仅为设计约束 | **当前实现未验收** | 不得据此宣称现有 UI、1.2.9 源码/产物或连接器已支持；实现阶段必须从真实 qB 5.2.4 独立验证 |
| 下载限制/队列 | `torrents/setDownloadLimit`、`setUploadLimit`、`setSuperSeeding` 等 | 待定白名单 | 每个端点单独验证 qB 5.2.4；不得透明开放未知 mutation |
| RSS/搜索/transfer | 各 qB API | 不首版承诺 | 仅在 MoviePilot 实际需要且完成标准 API 验证后加入 |

### 5.1 代理与透明转发判定

- **透明白名单**：只读、字段语义无需转换、无敏感响应头的 qB 端点；仍执行鉴权、来源、超时、大小和日志脱敏。
- **代理实现**：添加/删除/控制任务、分类/标签写操作；需要参数约束、幂等/未确认语义、结果回读和危险动作策略。
- **拒绝**：未知路径、调试端点、系统文件、任意 qB 管理路径、带外部回调的 URL、试图改变 Connector 监听/凭据的请求。

### 5.2 连接测试只读序列

1. 以专用凭据 POST 标准 auth/login，建立连接器会话；测试后注销。
2. GET `app/version` 或 `app/webapiVersion`。
3. GET `torrents/info`，限制 `limit=1` 或等价小响应。
4. GET `torrents/categories` 与 `torrents/tags`，只验证可读性。
5. 可选 GET `app/preferences`，只读取并过滤敏感字段。
6. 展示“认证成功 / qB 版本 / API 可用 / 标签分类可读”；任何一步失败显示固定错误和下一步建议。

测试允许标准 auth/login（POST）和 auth/logout（POST）仅改变连接器会话，业务读取仅 GET；不得向 qB 转发任何业务写请求。测试前后记录请求计数及任务/标签/分类快照，断言零新增、零业务状态变化。

## 7. 生命周期语义

- **启动**：读取已保存配置；禁用则不创建监听；启用则先验证权限、监听 IP/端口、qB loopback 可达性和凭据验证材料，再创建入口。任一失败保持关闭并进入错误态。
- **重启**：关闭旧 listener、撤销旧会话、重新加载配置；不自动生成新密码，不扩大 allowlist。启动失败不得保留半开入口。
- **升级**：保留启用状态和凭据引用，但升级迁移前做 schema/version 校验；无法安全迁移时自动禁用并提示管理员，不回退到明文。升级不改变端口或网络范围。
- **禁用**：先拒绝新请求，再关闭 listener，撤销会话/缓存的验证结果，清理内存中的密码明文；页面读回状态必须为 disabled。
- **卸载/恢复**：需明确是否删除凭据；备份不得包含可直接读取的明文密码。恢复后的旧授权/会话不可复活。
- **配置写入**：校验完整配置后原子提交；保存失败不能覆盖旧的可用配置，也不能把入口切换到部分新配置。

### 9.2 路径映射独立必需验收（不是分类路径）

MoviePilot **容器路径 ↔ qB 实际 NAS 路径**须单独记录映射对、挂载来源、读写权限和大小写/前缀边界；不得把“分类 savePath 已保存”或 API 已连接当作文件可达。示例只作占位 `MP:/<容器下载根> ↔ qB:/<实际NAS下载根>`，不猜真实卷路径。

后续授权的隔离安全任务验收：读取 qB info 的 save_path/content_path，确认 NAS 上文件实际存在；在 MoviePilot 容器按映射读取同一文件并核对内容/大小，验证 MoviePilot 所需权限及整理/硬链接条件（如适用）。重启后映射仍有效；缺挂载、错前缀、权限不足都必须失败且可恢复，不自动移动/删除用户数据。不隐式改 qB 分类路径或自动管理偏好。只读连接测试只报告映射“未验收”，不自行创建文件完成该验收。

所有上述网络、listener、凭据、backend 与路径测试当前均为 **待实施探测/待实机验收**，不是本次已执行证据。

## 10. 已定决策与剩余实施探测/启用门禁

1. **部署关系已确定**：同 NAS Docker 容器，已通过 host.docker.internal 访问宿主；不再作为用户待确认事项。
2. **入口契约已确定、数值待实施探测**：标准 HTTP qB 兼容入口，host.docker.internal 客户端地址；18081 proposed；实际解析目标、可绑定接口 IP、最小来源 allowlist、端口冲突与 TLS 需要实机验证。
3. **凭据存储**：fnOS/包运行时是否提供可用系统密钥存储？若没有，确认包私有 `0700/0600` 路径及真实 NAS ACL 可接受性。
4. **Connector 账号模型**：单一 MoviePilot 服务账号，还是多个账号？首版建议单账号、管理员可轮换，避免复杂账户管理。
5. **初始密码策略**：是否采用管理员首次设置的随机高熵密码；是否允许生成一次性显示/导出（建议不导出）。
6. **qB 认证边界**：Connector 到 loopback qB 如何获得最小必要权限，且不读取/暴露现有内部密码；需确认 qB 原生认证和本机代理身份方案。
7. **写操作范围**：MoviePilot 是否必须拥有删除任务、暂停/恢复、限速等能力；默认只开放添加、读取和标签/分类所需最小集合，危险写操作逐项批准。
8. **透明兼容范围**：是否允许后续增加 MoviePilot 需要但未列出的 qB API；任何扩展必须更新白名单、需求矩阵和回读验收。
9. **监听端口分配**：专用端口的具体值、配置方式、冲突处理和升级保留规则。
